# Time Tracking Tool

A simple web-based Time Tracking Tool developed using Python, Flask and SQLite.

## Features

- Add Activity
- Start Timer
- Stop Timer
- Category-wise Tracking
- Daily Total
- Time Usage History

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install Flask:

   pip install Flask

2. Run the application:

   python app.py

3. Open the browser:

   http://127.0.0.1:5000

## Database

The SQLite database is created automatically when the application starts.

## Purpose

This project helps users record activities, track time,
organize activities by category and view time usage history.
